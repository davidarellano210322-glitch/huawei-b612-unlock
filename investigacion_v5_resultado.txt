HALLAZGO #1 (el más importante): ¿Qué es realmente el unlock_v7r11?

El archivo "unlock_v7r11_2018-07-14.exe" NO es un calculador de códigos.
Es un INSTALADOR (Setup Factory de Indigo Rose). Le extraje el payload
oculto y encontré solo 3 archivos:

   bin/adb.exe        (el ADB de Google)
   bin/AdbWinApi.dll
   go.cmd             <-- EL SCRIPT REAL DEL DESBLOQUEO
   hideconsole.exe

El go.cmd hace esto (traducido del ruso):

   bin\adb connect <IP>:5555
   bin\adb shell busybox killall add_param
   bin\adb shell "atc AT^NVWREX=8268,0,12,1,0,0,0,2,0,0,0,A,0,0,0"
   bin\adb shell "echo -en 'AT^RESET\r' > /dev/appvcom1"

O sea: se conecta por ADB (puerto 5555), mata el daemon "add_param"
(el que aplica el bloqueo), ESCRIBE LA NVRAM con el mismo comando
AT^NVWREX=8268... que usa desbloquear_b612.py, y reinicia el módem.

CONCLUSIÓN: NO calcula ningún código. No existe calculador V5 para
esta familia. Por eso el autor del tool usó el bypass de NVRAM:
porque el código NO se puede derivar del IMEI (se genera en los
servidores/BD del operador). Lo mismo confirman huaweicalc (forth32)
y HMUC: solo implementan V1-V3 (dongles viejos), no V5 de routers.
